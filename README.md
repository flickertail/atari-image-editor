# Atari 2600 Image Editor

A browser-based editor that converts images and text into Atari 2600 graphics
(one color + one 8-pixel mask per group per scanline), with layers, undo/redo,
and export as a C header (`.h`).

Runs entirely in your browser - nothing is uploaded. Best in Chrome/Edge
(native "Save As" dialog); other browsers fall back to a normal download.
